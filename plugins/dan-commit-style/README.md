# dan-commit-style

What a branch's history looks like when it ships: themed commits.

```
/plugin install dan-commit-style@ffoxdd
```

One model-invoked skill, loaded when work is being committed or history
reshaped. It states requirements on the branch's final shape — each commit one
revert-coherent theme, green on its own, fewer and larger over many and pure —
and one flow for reshaping history that doesn't satisfy them. No hooks, nothing
injected per session, no enforcement.
